# BGS Car

Proyecto desarrollado para la Evaluación 1.

## Descripción

BGS Car es una aplicación web para el arriendo de vehículos que permite a los clientes explorar la flota, calcular la tarifa por días de reserva, gestionar un carrito de compras y acceder a paneles diferenciados según el rol de usuario (Cliente / Administrador).

## Tecnologías

- HTML
- CSS
- JavaScript
- Bootstrap

## Funcionalidades

- Página de inicio con buscador rápido y cálculo de días de reserva.
- Catálogo de flota con filtros dinámicos por categoría y transmisión.
- Carrito de compras interactivo con datos guardados en LocalStorage.
- Registro e inicio de sesión con validación de formularios y roles de usuario.
- Panel de administración para crear y gestionar la flota de vehículos.
- Secciones informativas de servicios, sucursales y contacto.
